# AST Explorer

An interactive, web-based tool for exploring Abstract Syntax Trees (ASTs) generated by Tree-sitter. Designed for clarity, performance, and serious code analysis.

## Features

- **Interactive Interactivity**: Select nodes in the Syntax Tree to highlight their range in the editor, and vice-versa.
- **Multi-Language Support**: Explore code in Javascript, Typescript, Python, Rust, C, and C++ via dynamic grammar loading.
- **Monaco-Powered Editor**: High-performance editing with basic syntax highlighting and precise range decorators.
- **URL-Based Persistence**: Snapshots of your code and selected language are persisted via query parameters for easy sharing.
- **Responsive Design**: Clean, functional layout that scales from mobile devices to extra-large desktop monitors.
- **Neutral Visual System**: A calm, pastel-based UI designed to minimize eye strain and maximize focus.

## Tech Stack

- **Framework**: Next.js (App Router)
- **Runtime**: React 19
- **Parsing Engine**: Web Tree-sitter (WASM)
- **Editor**: Monaco Editor
- **Styling**: Tailwind CSS
- **Typing**: TypeScript

## Getting Started

### Prerequisites

- Node.js (Latest LTS recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Kartik213/AST-Explorer.git
   cd ast-explorer
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

The application will be available at `http://localhost:3003`.

## Project Structure

```text
├── app/                  # Next.js App Router pages and layout
├── components/           # UI Components
│   ├── ast/              # Tree visualization logic
│   ├── editor/           # Monaco integration and controls
│   └── layout/           # Global header and HUD elements
├── hooks/                # Custom logic (Tree-sitter init, URL sync, Decorations)
├── lib/                  # Utilities and constants
├── public/               # WASM grammars and static assets
└── types/                # Shared TypeScript definitions
```

## Supported Languages

The explorer currently supports:
- JavaScript / TypeScript
- Python
- Rust
- C / C++

Adding a new language involves placing the corresponding `.wasm` grammar in the `public/` directory and adding the mapping to `lib/constants.ts`.
